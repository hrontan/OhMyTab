# OhMyTab

[English](README.md) / [日本語](README-ja.md) / 中文 (简体)

OhMyTab 提供了七个主要功能：

1. 将多个窗口中的选项卡合并到一个窗口
2. 关闭重复的选项卡
3. 按页面标题或 URL 对选项卡进行排序
4. 关闭系统选项卡和搜索引擎结果选项卡
5. 在扩展图标上显示选项卡数量（全部或每个窗口）
6. 在右键菜单中添加以下功能：
   - "关闭同一域名的选项卡"
   - "提取同一域名的选项卡到新窗口"
   - "将选项卡合并到一个窗口"
   - "提取当前选项卡到新窗口"
7. 根据域创建选项卡组
8. 关闭与模式匹配的 URL 的选项卡

您可以通过选项页面单独启用或禁用这些功能。
