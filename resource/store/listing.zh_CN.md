# 商店介绍（简体中文）

## 名称

OhMyTab

## 摘要

使用 OhMyTab 将分散的标签页聚合到一个窗口，删除重复标签页，并按 URL 或标题排序。

## 详细说明

一键整理分散的标签页。
点击工具栏上的 OhMyTab 按钮，即可一次性执行在选项页面中启用的所有标签页整理操作。

■ 一键操作（通过工具栏按钮）
・将同一会话中的标签页合并到一个窗口
・关闭 URL 相同的重复标签页
・按 URL 或页面标题对标签页进行排序
・关闭系统页面、搜索引擎结果页面和本地文件
・关闭与指定 URL 模式匹配的标签页（每行一个 glob 规则，不支持正则表达式）
・重新加载因浏览器节省内存而休眠的标签页
・将同一域名的标签页分组，自动以域名命名并折叠（仅限 Chrome 系浏览器）
・仅对当前窗口执行操作

■ 右键菜单操作
・关闭同一域名的标签页
・将同一域名的标签页移至新窗口
・将标签页合并到一个窗口
・将当前标签页移至新窗口
・指定子域名级别，关闭或移动该域名下的标签页
・运行已保存的工作流（运行前确认目标标签页）

■ 保存工作流
可在选项页面中，将目标窗口、操作和 URL 条件（主机名、包含子域名的主机名、包含的文本或 URL glob）组合命名并保存为工作流（最多 20 个）。已保存的工作流可从页面右键菜单的“整理步骤：名称”运行。运行前一定会打开确认页面，确认之前不会更改任何标签页。正在编辑的工作流也可以在保存前检查目标标签页。工作流仅保存在此浏览器中，不包含在浏览器同步或 JSON 备份中。

■ 标签页数量角标
在扩展图标上显示当前打开的标签页数量，可选择显示所有窗口的总数或每个窗口的数量。

■ 键盘快捷键
可以通过浏览器的扩展快捷键设置，为主要功能分配自定义快捷键。

■ 操作结果与状态
将鼠标悬停在扩展图标上，即可通过工具提示查看上次操作的结果。如果请求未被执行（例如另一操作仍在进行中），图标上会显示红色的“!”。

■ 保护、执行前预览与撤销
・保护：固定的标签页始终不参与操作。操作绝对不会跨越普通窗口与隐私窗口，在 Firefox 中也会严格隔离容器（Containers）。您还可以设置保护特定域名、正在播放音频的标签页以及现有分组内的标签页。
・优先级：保护规则优先。在删除重复项时，默认保留列表中的最后一个合格标签页，但也可设置为优先保留当前活动的标签页。
・预览（确认画面）：默认关闭。启用后，您可以在确认执行前查看目标标签页及关闭原因（取消则不会更改任何标签页）。预览数据最长在内存中保留 60 秒，若后台进程停止或重启则会立即失效。
・撤销（恢复）：扩展会在内存中短暂保留普通窗口中最近一次关闭的标签页记录（仅限 HTTP/HTTPS，最多 50 个，最长 5 分钟），以便您恢复。后台进程停止或重启时，记录可能在 5 分钟之前消失。标签页将在其原有的窗口中通过 URL 重新打开，因此表单输入内容和单个标签页的浏览历史不会被恢复。

■ 设置与 JSON 备份
URL 规则（开关及模式文本）可选择保存在本地设备（Local）或通过浏览器同步（Sync）。包括保护域名在内的其他设置将保留在浏览器同步中。切换到本地后，如果删除旧的同步副本失败，同步中可能残留副本；即使明确删除，也无法删除同步提供商的备份或其他设备上的副本。
您可以将设置导出或导入为 JSON 文件（版本 1，最大 64 KiB，UTF-8），在应用导入的设置前会有确认提示（取消则保留当前设置）。导出的 JSON 文件不包含您的保存位置偏好、浏览历史以及预览/撤销记录。

■ 隐私
标签页的 URL 和标题完全在浏览器本地处理，仅用于标签页管理、预览和撤销功能，OhMyTab 绝不会将数据发送到开发者的任何外部服务器。但是，如果您使用了浏览器的同步功能（Sync），设置（如 URL 模式和受保护的域名，可能包含敏感信息）将会通过您的浏览器账户进行同步。请在同步或分享 JSON 备份文件时注意信息安全。被恢复或重新加载的标签页将向其对应的网站发起正常的网络请求。

支持的浏览器：Chrome 123 或更高版本，Firefox 112 或更高版本（桌面版）。Microsoft Edge 和 Brave（桌面版）也可使用 Chrome 构建版本运行（已在基于 Chromium 156 的版本上测试；设备间同步未经测试）。
