# OhMyTab

[English](usage.md) / [日本語](usage-ja.md) / 中文 (简体)

## 安装

加载本地构建时，请按[开发流程](development.ja.md#ビルドと拡張機能の読み込み)操作：Chrome 加载未打包的 `dist_chrome/`，Firefox 选择 `dist_firefox/manifest.json` 作为临时附加组件。这些本地加载步骤不会发布扩展。

OhMyTab 提供以下八项主要的选项卡管理功能。

1. 将多个窗口中的选项卡合并到一个窗口。
2. 关闭 URL 相同的重复选项卡。
3. 按页面标题或 URL 排序。
4. 关闭系统页面和受支持的搜索结果页面。
5. 在图标上显示总数或每个窗口的选项卡数量。
6. 在右键菜单中关闭同一域名的选项卡、将其提取到新窗口、合并窗口或提取当前选项卡；详细菜单可选择子域名级别。
7. 按域名创建选项卡组（仅限 Chrome）。
8. 关闭 URL 与 glob 模式匹配的选项卡。

在选项页面中选择全局操作。全局 URL 规则每行一个 glob，去除行首行尾空白、忽略空行，多行按 OR 匹配；不是正则表达式。启用的规则最多 100 个非空行，每行去除空白后最多 1024 个 UTF-16 代码单元，包含 JSON 编码及键名的保存大小最多 8192 字节。启用的规则无效时，在更改选项卡前停止批量操作。

## 已保存的工作流

在选项页面的“已保存的工作流”中保存命名整理流程，与全局设置分开管理。

1. 选择“新建”，输入工作流名称并添加命名 URL 规则。每条规则都有启用开关，任一启用规则匹配即可（OR）。空条件无效。
2. 选择匹配方式。“主机名”可输入 `example.com`；选择“包含子域名（仅主机）”后也匹配 `news.example.com`，但不匹配 `evil-example.com` 或查询参数中的域名文本。“包含字面文本”区分大小写。“URL glob”沿用现有通配符及子串匹配方式，不是正则表达式。
3. 选择操作和范围：“右键所点标签页的窗口”或“起点会话中的所有窗口”。合并需要所有窗口。匹配规则的选项卡会被关闭；所选的去重、排序、合并、重新加载等操作也可影响该范围内其他符合条件的选项卡。
4. 展开“目标 URL 条件”编辑规则。已保存的条件最初也保持折叠。保存时如有无效条件，会展开此区域并将焦点移至相应字段。
5. 明确选择“保存”。从列表选择工作流即可加载内容；“加载所选工作流”可重新加载保存内容。重新加载此设置页会恢复选择。按需编辑、保存、复制或删除。

要检查当前有效的编辑内容，请选择“检查正在编辑的流程目标”，或某条规则旁的“检查此规则的目标”。普通编辑不会自动检查标签页。在“检查流程目标”中明确选择“基准标签页”，再选择“检查目标”。若没有可用标签页，请在普通网页所在的同一窗口和浏览会话中打开设置，再重新打开对话框。检查会应用当前的标签页保护设置。检查整个流程仅显示目标；如需执行整个流程，请保存后使用网页右键菜单。

检查单个规则时，即使该规则在流程中已禁用，仍会使用所选规则。此例外适用于本次明确检查和单规则关闭。关闭操作仅关闭该规则的目标，不执行流程中的其他操作。使用有效但未保存的编辑内容时，请先检查，再选择“使用此未保存的规则进入确认”。选择“预览仅关闭此规则的目标”打开新的预览，重新查看目标，并在该页面确认关闭。仅检查目标不会关闭标签页。

检查结果在60秒后过期。标签页变化也可能使显示结果过时，请重新检查后再继续。更改编辑内容、基准标签页、检查模式、所选规则、已保存的流程或保护设置，或关闭检查对话框，也会使相关的执行确认失效。查看单独的预览时，请保持检查对话框打开且内容不变。执行预览有独立的有效条件和期限；检查结果的60秒期限不会延长预览的期限。

运行时，在起点网页的右键菜单中选择“整理步骤：名称”→目标预览→确认。工作流与其他 OhMyTab 操作位于同一层级；浏览器可能将扩展菜单项自动放在扩展名称的父菜单中。此菜单仅使用保存内容，并固定调用时的标签页和窗口为起点。旧版本菜单会被拒绝；保存或删除后更新菜单，后台重启后仍验证保存版本。

运行已保存的工作流需要确认，即使全局预览已关闭。查看确认页面后再运行；取消不更改工作选项卡。执行时应用当前全局保护和重复项保留策略，排除固定选项卡、其他隐私／容器会话及本扩展的所有页面。起点移动、关闭或不可用时，重新打开网页右键菜单并检查，不会改用其他窗口或会话。Firefox 不支持分组；确认页面与起点不在同一容器时也会停止执行。

草稿不会自动保存。切换内容时选择“保留草稿”或“丢弃并继续”。保存失败或其他页面同时修改时保留输入，并显示冲突处理选项。“恢复为已保存内容”丢弃当前输入并读取保存内容，不写入设置。“用当前编辑内容覆盖”检查最新保存版本后，将当前输入明确保存并替换该版本，不自动合并更改。若已保存工作流已被删除，无法覆盖，当前输入仍保留在页面中。对于尚未保存的新工作流，“保存当前输入”会新建工作流，“恢复为已保存内容”则丢弃输入并重新加载保存列表。这些选项仅在冲突或无法确认保存结果时显示。

“复制全局 URL 规则”将现有模式追加为已启用的 glob 规则；“复制全局操作”将操作和范围复制到草稿。这些明确复制、选择和执行均不修改全局设置。图标、快捷键和原有操作菜单仍使用全局设置。

工作流保存在此浏览器的 local 存储中，浏览器重启后仍保留。不支持同步，不包含在设置 JSON version 1 中，也没有独立的导入／导出功能。上限为 20 个工作流、每个工作流 100 条规则、每个名称 80 个 UTF-16 代码单元、每个条件 1024 个代码单元，以及包含键名的编码存储总量 256 KiB。现有全局 URL 规则的限制另计。

## 保护、确认与恢复

固定选项卡不参与操作，也不会跨越请求来源的普通／隐私会话。Firefox 还会隔离不同的 cookie-store／容器；来源会话不明时不执行。可保护指定域名、正在播放音频的选项卡或现有组。保护优先于重复项选择；默认保留最后一个合格的重复项，也可优先保留活动选项卡。

全局操作的执行前预览默认关闭。预览显示目标 ID、原因、排除项和窗口范围。取消不更改工作选项卡；确认时重新验证原计划，不添加计划外的 ID。内存中只保留一份计划，最长 60 秒；后台停止或重启时可提前失效。

恢复只记录普通／默认会话中已确认关闭且符合条件的 HTTP(S) 选项卡。仅在内存中保留最近一次合格关闭，最多 50 项、最长 5 分钟；后台停止或重启时可能提前消失。只能在仍存在的原窗口重新打开 URL，不恢复表单、浏览历史或分组。隐私会话、非默认容器及不支持的 URL 不记录。

## 设置与敏感信息

设置通常保存在浏览器同步存储中。在全局设置中，只有 URL 规则开关和模式文本两项可改用 local；保护域名等其他设置仍在 sync。移除失败或其他设备更新时可能留下旧 sync 副本，页面会显示残留并提供明确的移除操作；无法保证删除提供商备份或其他设备的副本。

设置 JSON 使用 28 个已知字段、`ohmytab-settings`、version 1，UTF-8 最大 64 KiB。先查看内容，再明确应用；取消不改变设置。保存位置、浏览历史、preview／undo 记录和恢复数据不导出。Firefox 保留共享的 Chrome 分组设置。URL 模式和保护域名可能包含敏感信息，请确认浏览器同步目标和 JSON 的共享位置。

目标为桌面版 Chrome 123+、Firefox 112+；Firefox 不支持分组。Microsoft Edge 和 Brave 桌面版使用 Chrome 构建版本，功能相同（已在基于 Chromium 156 的版本上测试；设备间同步未经测试）。声明的最低版本不等于已完成最低版本或整个发布候选的验证。参阅[浏览器支持](browser-support.ja.md)、[开发与验证限制](development.ja.md)、[操作边界](domain-operations.ja.md)和[设置详情](settings-sync.ja.md)（日语）。

全局 URL 规则及其存储选择器、选项卡保护和重复项保留策略按功能分组，位于默认折叠的“高级功能”中。已有值保持不变；启用时外部也会显示提示。写入 `storage.sync` 成功仅表示保存到浏览器同步存储区域，无法确认设备间同步是否完成。Chrome、Edge 和 Brave 依赖同一浏览器、同一扩展 ID、相应的配置文件及浏览器同步设置，不保证跨浏览器同步。`local` 仅保存在此配置文件中。Edge/Brave 设备间同步尚未经过实机验证。

不支持退出浏览器时自动执行：[runtime.onSuspend](https://developer.chrome.com/docs/extensions/reference/api/runtime#event-onSuspend) 是事件页面卸载前的通知，不保证异步操作完成。退出前请从网页右键菜单选择工作流，检查预览并确认。
