# 操作の実行と結果

ボタン、ショートカット、メニューの変更処理は、共通の実行状態で重複を防ぎます。操作中の追加要求は実行せず、完了後の再試行を案内します。説明はマウスポインターを置かないと見えないため、要求元のタブのバッジに赤い「!」を2秒間表示して、実行しなかったことを示します。待機列に保存して後から破壊的な操作を重ねることはありません。

操作開始時に要求元と同じセッションのウィンドウ、固定・保護タブを除くタブID、開始ウィンドウ、選択タブを取得します。その後にフォーカスが変わっても対象を広げません。新しく作成されたタブは追加しません。ソートはウィンドウごとにタブの並びを一度取得し、移動のたびにその並びを手元で更新して位置を計算します。移動が失敗したときだけ並びを取得し直します。対象は開始時のIDに限定します。メニューのドメインと範囲には、クリック時の公開済み表示を使います。

結果はツールバーのOhMyTabアイコンにマウスポインターを置くと表示される説明に残ります。操作中、追加要求の不実行や結果を3言語で表示します。タブ数バッジは引き続きタブ数を表します。操作中はタブイベントによるバッジとメニューの更新を止め、操作の終了時にまとめて反映します。

破棄されたタブの再読み込みは同時に4件までとし、各タブの読み込み完了（最長5秒）を待って次のタブへ進みます。多数のタブを一斉に読み込んでブラウザーが固まるのを避けるためです。その分、操作の完了までの時間は長くなります。

タブのグループ化では、グループに属していないタブへの `ungroup` を呼びません。移動対象のグループがすでにタイトル順で先頭に並んでいる場合は、グループを移動しません。

対象の取得と選定に成功して対象が0件になった場合は、タブの閉鎖・移動・再読込やウィンドウ作成のAPIを呼びません。対象・完了・失敗・不明がすべて0件の結果を表示し、実行状態を解除して次の操作を受け付けます。空白だけのURLルールも、どのURLも選択しないためこの扱いです。対象取得APIの失敗は0件の成功ではなく「操作を停止しました」とAPIエラー件数を表示し、再試行できる状態へ戻ります。

件数は変更を試みたタブの重複しないID数です。「完了」はAPIが完了した、またはAPI拒否後の照合で要求した状態を確認できた件数です。閉鎖の場合は消滅済み、移動の場合は指定したウィンドウ・位置を確認します。他の操作によるタブ消滅と拡張機能自身の閉鎖を区別することはできません。「失敗」は拒否または未達を確認した件数、「不明」は照合用APIも失敗した件数です。一度失敗・不明となったIDは、後続処理が完了してもその表示を保持します。APIエラー件数はタブ件数とは別で、フォーカス変更なども含みます。

一部失敗でも他の独立した対象を処理し、結果を表示します。開始対象の取得や設定検証などで継続できない場合は停止を表示します。正常終了・例外とも実行状態を解除します。通知API自体が失敗した場合には結果表示を保証できませんが、実行状態は解除します。APIの拒否内容、閲覧URL、保存済みパターンを操作ログへ出力しません。

セッション境界、保護条件、実行前の確認、閉じたタブの復元は[対象範囲の説明](domain-operations.ja.md)を参照してください。[設定同期](settings-sync.ja.md)と[URLパターン仕様](pattern-matching.ja.md)も維持します。回帰はAPIモックによるもので、実ブラウザの表示やアカウント同期は別途確認します。

説明のAPIは [Chrome action](https://developer.chrome.com/docs/extensions/reference/api/action) と [MDN action.setTitle](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/action/setTitle) を参照しました。Chromeでは説明がスクリーンリーダーの読み上げにも使われます。
