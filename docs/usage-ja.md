# OhMyTab

[English](usage.md) / 日本語 / [中文 (简体)](usage-zh_CN.md)

## 導入

ローカルビルドの読込みは[開発手順](development.ja.md#ビルドと拡張機能の読み込み)に従う。Chromeでは `dist_chrome/` をパッケージ化されていない拡張機能として読み込み、Firefoxでは `dist_firefox/manifest.json` を一時的なアドオンとして選ぶ。この操作でストアへ公開されることはない。

OhMyTabには次の八つのタブ管理機能があります。

1. 複数ウィンドウのタブを一つのウィンドウに集約する。
2. 同一URLの重複タブを閉じる。
3. URLやページタイトルでタブを並べ替える。
4. システムページと対応する検索結果のタブを閉じる。
5. 全体またはウィンドウごとのタブ数をアイコンに表示する。
6. 同じドメインの閉鎖・新規ウィンドウへの抽出、ウィンドウ集約、現在タブの抽出を右クリックメニューに追加する。詳細メニューではサブドメインの階層を選べる。
7. ドメインごとにタブグループを作る（Chromeのみ）。
8. globパターンに一致するURLのタブを閉じる。

設定画面で共通設定の操作を選びます。共通のURLルールは1行1glob、前後の空白を除き空行を無視し、いずれかのルールに一致するOR条件です。正規表現ではありません。有効なルールは空行を除いて100行、空白除去後1行1024 UTF-16コード単位、JSON化とキー長を含む保存サイズ8192バイトまでです。有効なルールが不正な場合、一括操作を変更前に停止します。

## 保存した整理手順

設定画面の「保存した整理手順」で、共通設定とは別に名前付きの整理手順を保存できる。

1. 「新しい手順を作る」を選び、手順の名前と名前付き URL ルールを入力する。各ルールには有効・無効の切替があり、有効なルールのいずれかに一致すれば対象となる（OR）。空の条件は入力エラーとなる。
2. 一致方式を選ぶ。「サイト名」には `example.com` を入力でき、「下位のサイトも含める（サイト名で探す場合）」を選ぶと `news.example.com` も対象となる。`evil-example.com` やクエリー内のドメイン文字列には一致しない。「URLに含む文字」は大文字・小文字を区別する。「URLのパターン（*など）」は従来のワイルドカードと部分一致の方式であり、正規表現ではない。
3. 操作と対象範囲を選ぶ。範囲は「右クリックしたタブのウィンドウだけ」か「すべての対象ウィンドウ」であり、結合には全ウィンドウの指定が必要となる。ルールに一致したタブは閉鎖対象となる。重複削除・並べ替え・結合・再読込などの選択した操作は、同じ範囲内の他の適格タブにも適用される。
4. 「対象URLの条件」を開いてルールを編集する。保存済みの条件も初めは折りたたまれている。保存時に条件の入力エラーがあれば、この欄を開いて該当項目へフォーカスを移す。
5. 「手順を保存」を明示的に選ぶ。一覧で手順を選ぶと内容を読み込み、「選んだ手順を読み込む」で保存内容を読み直せる。この設定タブを再読み込みしても選択を復元する。編集・保存・複製・削除を必要に応じて行う。

有効な入力内容の対象を調べるには、「編集中の手順の対象を確認」か、各ルールの「この条件の対象を確認」を選ぶ。通常の編集では、タブの対象を自動で調べない。「整理手順の対象を確認」で「基準にするタブ」を明示的に選び、「対象を確認する」を押す。使えるタブがない場合は、通常のページと同じウィンドウ・閲覧セッションで設定画面を開き、確認画面を開き直す。現在のタブ保護設定を適用する。手順全体の確認は対象の表示だけであり、全体を実行するには保存後にページの右クリックメニューを使う。

ルール単独の確認では、手順内で無効になっているルールも選択条件として使う。この例外は、明示的な対象確認と、そのルールだけでタブを閉じる操作に適用する。閉じるのは選択したルールの対象だけで、手順の他の操作は実行しない。有効な未保存の入力内容を使う場合は、対象を確認した後に「保存前のこの条件で確認へ進む」を選ぶ。「この条件の対象だけを閉じるために確認へ進む」で別の確認画面を開き、改めて対象を確かめてから、そちらで実行する。対象を確認するだけではタブを閉じない。

対象確認の結果は60秒で失効する。タブの変更で表示が古くなった場合も、対象を確認し直す。入力内容・基準のタブ・確認モード・選択ルール・保存した手順・保護設定の変更や、対象確認画面を閉じる操作では、関連する実行確認も無効になる。別の確認画面で対象を確かめている間は、対象確認画面を開いたままにし、内容を変えない。実行確認には別の有効条件と期限があり、対象確認の60秒という期限で延長されることはない。

保存した手順の実行は、起点にしたいページの右クリックメニューから「整理手順: 手順名」→対象確認→実行と進む。手順は他のOhMyTabの操作と同じ階層に並び、ブラウザーが拡張名の親メニューにまとめる場合がある。このメニューでは保存済みの内容だけを使い、呼び出したタブとウィンドウを起点に固定する。古い版のメニューは実行せず、保存・削除後にメニューを更新する。バックグラウンド再起動後も保存版を検証する。

保存した手順の実行は、共通の実行前確認が OFF でも確認画面を開く。対象を確認してから確定する。キャンセルでは作業タブを変更しない。実行時点の共通の保護設定と重複時の保持方針を適用し、固定タブ・別のプライベート／コンテナーのタブ・この拡張機能自身の全ページを除外する。起点が移動・終了した場合や不明な場合は、ページの右クリックメニューを開き直して確認する。別のウィンドウやセッションへ切り替えて実行することはない。Firefox ではグループ化を使えず、確認ページが起点と同じコンテナーにない場合も実行を停止する。

下書きは自動保存されない。編集中に別の内容へ切り替える場合は「編集を続ける」か「入力を捨てて続ける」を選ぶ。保存失敗や他の画面との競合では入力を保持し、使う内容を選ぶ欄を表示する。「保存済みの内容に戻す」は今の入力を捨てて保存済みの内容を読み込み、書き込みは行わない。「自分の編集内容で上書きする」は最新の保存状態を確認し、保持した入力を明示的に保存して置き換える。変更の自動統合は行わない。他の画面で削除された手順は上書きできず、入力は画面に残る。まだ保存していない新しい手順では、「この入力を保存する」で新規保存し、「保存済みの内容に戻す」で入力を捨てて一覧を読み直す。これらの選択肢は、競合時や保存結果を確認できなかった場合だけ表示する。

「上の設定からURLの条件をコピー」は従来のパターンを有効な glob ルールとして追加し、「上の設定から操作をコピー」は操作と範囲を下書きへ取り込む。これらの明示コピー、選択、実行によって共通設定を書き換えることはない。アイコン・ショートカット・従来の操作メニューは引き続き共通設定を使う。

ワークフローはこのブラウザーの local に保存され、ブラウザー再起動後も残る。同期、設定 JSON version 1 への格納、独自のインポート／エクスポートには対応しない。上限は20手順、1手順100ルール、名前80 UTF-16コード単位、条件1024コード単位、キーを含む保存データ全体256 KiBである。従来の共通 URL ルールの上限とは別である。

## 保護・確認・復元

固定タブは操作対象から除外し、要求元の通常／プライベート境界をまたぎません。Firefoxではcookie-store／コンテナーも分離します。要求元の状態が不明な場合は実行しません。保護ドメイン、音声再生中、既存グループの除外を選べます。保護を優先し、重複タブは対象内の最後を残すのが既定です。アクティブタブ優先も選べます。

共通設定による操作の実行前確認は既定でOFFです。対象ID・理由・除外・ウィンドウ範囲を表示し、キャンセルでは作業タブを変更しません。確定時は元の計画を再確認し、計画外のIDを追加しません。保持はメモリ内の1件、最長60秒で、バックグラウンド停止・再起動では期限前にも失効します。

復元できるのは、通常・既定セッションで閉鎖を確認できた対象のHTTP(S)タブです。直近の対象閉鎖1回、最大50件、最長5分をメモリだけに保持し、バックグラウンド停止・再起動で早期に消える場合があります。現存する元ウィンドウでURLを開き直す機能で、フォーム入力・閲覧履歴・グループは復元しません。プライベート、非既定コンテナー、対象外URLは記録しません。

## 設定と機密情報

設定は基本的にブラウザー同期の対象です。共通設定でlocalへ切り替えられるのはURLルールの有効・無効とパターン文字列の2項目だけで、保護ドメインや他の設定はsyncに残ります。除去失敗や別端末の変更により旧syncコピーが残る場合は表示し、明示的な除去を選べます。提供元のバックアップや他端末のコピーまで消す保証はありません。

設定JSONは既知の28項目、`ohmytab-settings`・version 1、UTF-8で最大64KiBです。内容を確認してから適用し、キャンセルでは設定を変えません。保存先、閲覧履歴、preview／undoの記録、復旧データは出力しません。Firefoxでは共有Chromeグループ設定を保持します。URLパターンと保護ドメインに機密情報が含まれる場合は、ブラウザーの同期先とJSONの共有先を確認してください。

対象はデスクトップ版Chrome 123以降、Firefox 112以降です。Firefoxではグループ化を使えません。Microsoft EdgeとBraveのデスクトップ版では、Chrome用のビルドで同じ機能を使えます（Chromium 156ベースの版で確認。端末間の同期は未確認）。宣言下限と、最低版・配布候補全体の検証済み範囲は区別します。[ブラウザー別対応](browser-support.ja.md)、[開発手順と検証上の制約](development.ja.md)、[操作の境界](domain-operations.ja.md)、[設定の詳細](settings-sync.ja.md)を参照してください。

共通のURL指定機能と保存先、操作しないタブ、重複時に残すタブの設定は、閉じた「高度な機能」の中で機能別にまとめている。保存値は変えず、有効な場合は外側にも表示する。`storage.sync` への保存成功はブラウザーの同期用領域への書き込みを示し、端末間の同期完了は確認できない。Chrome・Edge・Braveでは同じブラウザー・同じ拡張ID、利用するプロファイルとブラウザー側の同期設定に依存し、異なるブラウザー間の同期は保証しない。`local` はこのプロファイルだけに保存する。Edge・Braveの端末間同期は実機未検証である。

ブラウザー終了時の自動実行には対応しない。[runtime.onSuspend](https://developer.chrome.com/docs/extensions/reference/api/runtime#event-onSuspend) はイベントページを破棄する前の通知であり、非同期処理の完了を保証しない。終了前にページの右クリックメニューから手順を選び、対象を確認して実行する。
